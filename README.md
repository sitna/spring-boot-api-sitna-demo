# spring-boot-api-sitna-demo
Proyecto de demostración que ilustra el uso de [api-sitna](https://github.com/sitna/api-sitna) mediante Spring Boot.

Para arrancarlo hay que ir a la ruta local del proyecto y ejecutar este comando:

`mvnw spring-boot:run`

La aplicación web se mostrará en http://localhost:8080/.

---

Demo project that illustrates the use of [api-sitna](https://github.com/sitna/api-sitna) with Spring Boot.

To launch, go to the project local path and run this command:
```
mvnw spring-boot:run
```
The web application will be launched at http://localhost:8080/.
